# Python Beginner Module Package

- This module made specifically for beginners to learn from.

## What's the matter?

- This module helps new-bie Python Learners to understand how the module actually works.
- The module has the ordinary commands for terminal-based Projects

## How to import Local Modules?

- To import Local modules in Python:
    1. You need to add the Module file into the project directory.
    2. Make sure the `module.py` is in the `main.py` directory.

## How to use the commands in the module?

1. Import the module
2. Call the functions in the module by `module_name.command_name()`
    - Notice how the module works in projects.

## How to import a specific command?

- You import it by using `from module.py import command`
- If you want to import the module with custom name?
    1. You type `import module.py as (custom name)`

## Why do we create modules?

- To type more well-structured code
- Don't need to type the exact same functions in every project
